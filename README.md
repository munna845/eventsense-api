#  Event Management & Recommendation System

A full-featured Event Management REST API built with **Django** and **Django REST Framework (DRF)**.  
This system allows users to register, manage their interests, create events, and receive personalized event recommendations and notifications when new events match their interests.

---

## Features

- **User Management** — Custom user model with phone and multiple interests.  
- **Personalized Recommendations** — Suggests events based on users’ selected interests.  
- **Event Management** — Create, update, and list events with related interests and creators.  
- **Real-time Notifications** — Automatically notifies users when new events match their interests (via Django signals).  
- **Search & Filter** — Easily find events by interest, title, or location.  
- **Authentication** — Secure registration and login system using DRF authentication.  
- **Admin Dashboard** — Manage users, events, and interests from Django admin.  

---

## Tech Stack

- **Backend:** Django, Django REST Framework  
- **Database:** PostgreSQL / SQLite  
- **Authentication:** Token / Session Authentication  
- **Tools & Libraries:** Django Filters, Signals, REST Framework, Python 3.x
